## このサイトについて

このサイトは、FlutterやReactの経験があり、これからJetpack ComposeとKotlinを学習する方向けの実践的な学習ガイドです。

### 対象者

- FlutterまたはReactの開発経験がある方
- Androidアプリ開発をこれから始める方
- Jetpack ComposeとKotlinを短期間でキャッチアップしたい方

### 学習の進め方

1. **[イントロダクション](/guide/introduction)** - Jetpack Composeの概要を理解
2. **[Flutter/React比較](/guide/comparison)** - 既知の概念との対応を確認
3. **Kotlin基礎** - Kotlin言語の基本を習得
4. **Jetpack Compose基礎** - Composableとstate管理を学習
5. **実践例** - 実際のアプリを作りながら理解を深める

### 必要な前提知識

- FlutterまたはReactの基本的な知識
- 宣言的UIの概念理解
- 基本的なプログラミング知識

それでは、[学習を始めましょう](/guide/introduction)！
