## 🚀 ローカル開発

### 前提条件

- Node.js 18以上

### セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run docs:dev

# ビルド
npm run docs:build

# ビルド結果のプレビュー
npm run docs:preview
```
